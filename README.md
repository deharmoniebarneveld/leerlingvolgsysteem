# leerlingvolgsysteem
We hebben diverse leerlingen die via cursissen starten en dan binnen de vereniging doorgroeien. We willen in deze app bijhouden welke route ze hebben gevolgt, waar ze staan in de ontwikkeling, hoe succesvol cursussen zijn geweest, wie in welk orkest zit en zorgen dat dit allemaal aansluit op de ledenadministratie.
